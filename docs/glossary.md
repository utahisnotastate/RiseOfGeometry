# Glossary

Plain-English definitions. Each entry links to the concept page where it matters.

| Term | Plain meaning |
|---|---|
| **Aharonov–Bohm effect** | An electron is affected by a magnetic field it never touches, through the potential around it. [03](concepts/03-forces-are-connections.md) |
| **Bekenstein bound** | The maximum information that fits in a region, set by its surface area. [10](concepts/10-information-lives-on-surfaces.md) |
| **Berry phase** | The "twist" a wave picks up after being carried around a loop. It depends only on the loop's geometry. [03](concepts/03-forces-are-connections.md), [07](concepts/07-topology-knots-and-whole-numbers.md) |
| **Casimir effect** | Two close metal plates are pushed together because they restrict vacuum fluctuations between them. [04](concepts/04-shape-picks-the-notes.md) |
| **Chern number** | A whole number measuring how "twisted" a material's electron waves are. It can't change gradually. [07](concepts/07-topology-knots-and-whole-numbers.md) |
| **Chladni figure** | The pattern sand makes on a vibrating plate. [04](concepts/04-shape-picks-the-notes.md) |
| **Connection** | A rule for comparing directions at nearby points. In physics, it's the gauge potential. [03](concepts/03-forces-are-connections.md) |
| **Continued fraction** | Writing a number as a whole number plus 1 over (whole number plus 1 over (…)). Small terms mean the number is hard to approximate with fractions. [05](concepts/05-the-golden-ratio-honestly.md) |
| **Cosmological constant problem** | Naive theory predicts vacuum energy about 10¹²³ times bigger than what's observed. [11](concepts/11-the-vacuum.md) |
| **Crystallographic restriction** | Repeating crystals can only have 1-, 2-, 3-, 4-, or 6-fold rotation symmetry. [06](concepts/06-the-allowed-shapes.md) |
| **Curvature** | How much a space bends. In GR, it's gravity. In gauge theory, it's a force field. [02](concepts/02-gravity-is-shape.md), [03](concepts/03-forces-are-connections.md) |
| **Eigenmode** | A natural vibration pattern a system can hold on its own. [04](concepts/04-shape-picks-the-notes.md) |
| **Frame dragging** | A spinning mass drags spacetime around with it. [02](concepts/02-gravity-is-shape.md) |
| **Gauge theory** | The framework for all known forces, in which each force is the curvature of a hidden internal space. [03](concepts/03-forces-are-connections.md) |
| **Geodesic** | The straightest possible path in a curved space. [02](concepts/02-gravity-is-shape.md) |
| **Golden angle** | About 137.5°. The turn between successive seeds in a sunflower. [05](concepts/05-the-golden-ratio-honestly.md) |
| **Group velocity** | The speed at which a wave's energy and information travel. Never faster than light. [09](concepts/09-waves-that-run-backward.md) |
| **Holographic principle** | The idea that everything inside a region can be described by information on its boundary. [10](concepts/10-information-lives-on-surfaces.md) |
| **Ideomotor effect** | Small, unconscious muscle movements driven by expectation, as in Ouija boards and dowsing. [E007](../experiments/E007-blinded-radionics-test.md) |
| **KAM theorem** | In slightly disturbed orbits, those with "very irrational" frequency ratios stay stable longest. [05](concepts/05-the-golden-ratio-honestly.md) |
| **Landauer's principle** | Erasing one bit of information costs at least $k_B T \ln 2$ of heat. [12](concepts/12-boundaries-logic-and-computing.md) |
| **Laws of Form** | Spencer-Brown's logic built from the single act of drawing a boundary. [12](concepts/12-boundaries-logic-and-computing.md) |
| **Mach's principle** | The idea that inertia comes from all the matter in the universe. Still open. [02](concepts/02-gravity-is-shape.md) |
| **Noether's theorem** | Every continuous symmetry gives a conserved quantity. [01](concepts/01-symmetry-is-conservation.md) |
| **Phase conjugation** | Producing a wave that retraces the exact path of an incoming wave, undoing distortion. [09](concepts/09-waves-that-run-backward.md) |
| **Phase velocity** | The speed of a wave's crests. It can exceed light speed without carrying information. [09](concepts/09-waves-that-run-backward.md) |
| **Phyllotaxis** | The arrangement of leaves and seeds on a plant. [05](concepts/05-the-golden-ratio-honestly.md) |
| **Planck length** | About 1.6 × 10⁻³⁵ m, the scale where quantum gravity is expected to matter. [11](concepts/11-the-vacuum.md) |
| **Platonic solid** | One of the five convex solids with identical regular faces and identical corners. [06](concepts/06-the-allowed-shapes.md) |
| **Quasicrystal** | Ordered but never exactly repeating, allowing "forbidden" 5-fold symmetry. [06](concepts/06-the-allowed-shapes.md) |
| **Schumann resonances** | Natural electromagnetic resonances of the Earth–ionosphere cavity, starting near 7.83 Hz. [ledger D18](claims/ledger.md) |
| **Topology** | The study of properties that don't change when you stretch or bend, only when you cut or glue. [07](concepts/07-topology-knots-and-whole-numbers.md) |
| **Torus** | A donut shape. [08](concepts/08-vortices-and-tori.md) |
| **Vortex ring** | A spinning donut of fluid, like a smoke ring. [08](concepts/08-vortices-and-tori.md) |
| **Zero-point energy** | The minimum energy a quantum system keeps even at absolute zero. [11](concepts/11-the-vacuum.md) |
