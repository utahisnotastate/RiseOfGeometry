## Rules for every experiment

1. **Write down your prediction first.** What would you see if the idea is true? What if it's false?
2. **Change one thing at a time.**
3. **Repeat.** One result is an anecdote. Ten is data.
4. **Blind yourself when you can.** If *you* deciding the outcome is possible, arrange things so you can't know which condition you're in.
5. **Report failures too.** A clean "nothing happened" is a real result.
